# 星星俄罗斯方块

适合手机和电脑玩的单机俄罗斯方块。直接打开 `index.html`，不需要安装依赖。

- 10×20 格；七种彩色方块，七袋随机顺序。
- 填满一行即可消除得分，累计消除 10 行升一级，加快下落。
- 手机点屏幕按钮左移、旋转、右移、下落、落底；电脑用方向键、空格和 P 键。
- 可以暂停、继续、重新开始；切到别的标签页自动暂停。
- 连续消行有连击奖励：第二次连续消行额外获得 50 × 等级分，之后每次增加 50 × 等级分；没有消行会中断连击。
- 消行闪光和提示；最高分保存在本机浏览器（无账号）。
- 所有得分只是游戏分数，没有账号、广告或实际支付。
