# 俄罗斯方块

在线：https://zhaosongli.github.io/tetris-web/

## 玩法
- 8×8 放大棋盘，手机显示最大 340×340 像素；短屏幕使用 280×280，小屏幕使用 232×232。下面三个方块图形也已放大，原有拖动、托盘和消除规则保持不变。
- 不自动下落，不显示下一个方块。
- 下方三个方块可以任意顺序拖到棋盘空位，也可先点方块再点棋盘；方块不可重叠或越界。
- 三个全部用完才刷新下一组三个。
- 满行和满列同时消除，不会让其他方块下落；每格基础 1 分，每条线基础 100 分，连续消除有奖励。
- 初始倍率 ×1；每成功放一个方块，倍率加一至 ×2、×3、×4……无硬编码上限。先加入本次基础分和消除奖励，再将累计分数乘以新倍率。无效放置不增长。
- 分数与倍率使用 BigInt 精确计算，不会因数值变大变成 Infinity；长分数以科学计数法显示，标题提示保留完整数值。
- 剩余方块全都没有合法落点时判输，立刻清空棋盘和托盘，保留本局分数；停住显示本局最高倍率和分数，只有点重新开始才开新局。
- 最高分保存在当前浏览器 localStorage 的 234567-best 键，历史最高倍率保存在 tetris-best-multiplier；无账号、无广告、无支付。

## 运行与验证
无需构建或依赖，浏览器打开 index.html（同目录包含 game.js）。
带 ?test 参数打开页面，可使用 __blocks.fixture 构造测试局面。在浏览器执行 tests.js 可验证规则；test-results.json 记录本地浏览器实际执行结果。
已验证触摸指针拖动、行列交叉消除、托盘补充、越界/重叠拒绝、全无合法落点时清空、重新开始，以及 200 次模拟落子。
